32. Поиск корней непрерывной функции

Функция может быть произвольной, но непрерывной. Для выбора функции использовать указатель на функцию.
Реализовать следующие численные методы уточнения корней:
Метод последовательных приближений (метод итераций)
Метод Ньютона (метод касательных)
Метод секущих (метод хорд)
Метод половинного деления (метод дихотомии)
Задать несколько функций для тестирования.
Реализовать меню выбора метода.
